Starting the Spectrum…
Tap the keys like a 48K Spectrum: ⇧ is CAPS SHIFT and sym is SYMBOL SHIFT (tap one, then the key). Green words are what a key types in command mode; red is the symbol shift legend. Typing COPY (key Z) prints the screen, LPRINT and LLIST print text, just like on a ZX Printer.
Programs and tapes
Open accepts .TAP and .TZX tapes, .Z80 and .SNA snapshots, and a different 16K ROM (.rom or .bin), also inside a .ZIP. A ROM you load is remembered on this phone.
SAVE "name" (key S) records the program into this list automatically. Press a key when the Spectrum says “Start tape, then press any key”.
Type in a BASIC listing
Paste a listing from a magazine or book: each line starts with its number. Keywords in capitals (PRINT, GO TO, FOR…), variables in lower case or single capitals. The original Union Flag program is in Appendix D of the Spectrum manual: open it on World of Spectrum ↗, copy from “5 REM union flag” to line 690, paste it here, tap “Make a tape”, then LOAD and RUN.
Tap “Add ROM…” to pick a Game Boy ROM (e.g. camera.gb), or “From server” if your Mac is serving rom/camera.gb.
Sensor bright
ROMs and saves stay in this browser only. Supported cartridges: plain, MBC1, MBC2, MBC3 (with real-time clock), MBC5 (with rumble, which vibrates your phone), HuC1, HuC3 (clock is a stub) and Game Boy Camera. Game Boy Color games run in full colour, including Color-only games. Printing from any game that supports the Game Boy Printer comes out on the cat printer. In the Camera game: VIEW → photo → A → print.
